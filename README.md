# ConsumerCatFactApi 

Aplicação console em C# (.NET) que consome a API pública [CatFact](https://catfact.ninja/) e exibe um fato aleatório sobre gatos no terminal.

## 🌐 API Utilizada

- **Endpoint:** `https://catfact.ninja/fact`
- **Método:** GET
- **Retorno:** JSON com um fato aleatório sobre gatos

## 🛠️ Tecnologias

- C# / .NET
- `HttpClient` — para realizar requisições HTTP
- `Newtonsoft.Json` — para desserializar o JSON retornado pela API
